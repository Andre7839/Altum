Orthomosaic & bands

Load the multispectral GeoTIFF, check the band order, then continue to Calibrate. A DEM/DSM can be added below (optional).

Any band can be set to “none”. Defaults assume the order Blue, Green, Red, Red edge, NIR, Thermal. Divisor converts DN to 0–1 reflectance (1, 255, 10000 or 65535); it is auto-suggested on load.

Boundary calibration

Set the weather and the wet/dry reference temperatures used by ETa and CWSI, adjust canopy parameters if needed, then press Process.

Canopy & vegetation parameters

Auto mode sets the canopy threshold by Otsu's method and bare-soil / full-cover NDVI at the 5th / 95th percentiles. FVC = ((NDVI−soil)/(full−soil))², LAI = −ln(1−FVC)/k, fIPAR and Kcb are linear in NDVI. The slope/intercept values are generic literature-type defaults: calibrate them per crop before using absolute values.

Surface model / DEM (optional)

Adds Elevation, Slope, Northness, Eastness and plant height as layers and per-treatment statistics. May be a different CRS/resolution than the orthomosaic.

Plant height = DSM − ground. The local-percentile ground works when bare soil is visible within each block; in closed canopies it underestimates height, so use a bare-soil DEM or a larger block. Changes to these settings apply when you press Process.

Treatment boundaries & statistics

Load the plot polygons (after processing), choose the treatment field, compute the summary, then export.

Each polygon is treated as one plot (replicate). Plots sharing the same treatment value are pooled. Comparison: one-way ANOVA + pairwise Welch t-tests (Bonferroni) with letter groupings. Excel = all numbers; Report = one printable HTML summary of every parameter (tables, boxplots, formulas, meanings).
